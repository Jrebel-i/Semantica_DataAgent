# 基于个人 DTB 令牌的查询历史挖掘与受控数据探活外键发现

Status: accepted

现有 [0008](0008-dtb-to-ossie-pipeline.md) 仅从 DTB 产数任务 SQL 抽取表间关系，缺少对数仓真实业务**查询历史**中高频指标表达式、默认过滤规则与跨主题关联模式的挖掘；同时跨分层或未在同个产数任务共现的表之间缺乏经真实数据验证的候选**外键关系**。为在借鉴外部自动化语义挖掘优点的同时坚守 [0009](0009-git-backed-semantic-overrides-and-correction-policy.md) 与 [0010](0010-local-trajectories-and-candidate-generation-gate.md) 确立的源目录唯一权威、数据防泄漏与人工可控边界，第九期确立以下四项核心决策：

1. **项目级可配置查询历史源与受控只读 SQL 拼装**：每个**数仓型项目**支持配置一套**查询历史**源（内置「Doris 审计日志」与「DTB 埋点表」两套预设模板，允许自定义源表名、关键列映射、成功状态值、回溯天数与拉取行数上限）。服务端仅对合法标识符与白名单过滤条件通过 AST 拼装只读 `SELECT` 并强制 `LIMIT`，禁止任意自由 SQL 模板，避免注入与非只读语句风险；拉回结果按 `sqlglot` 剥离字面量并按结构指纹聚类，按执行频次与去重调用次数排序，剔除一次性探索查询。
2. **个人 DTB 令牌手动触发与全量查询审计**：**知识发现运行**仅允许项目管理员与系统管理员手动触发，执行日志拉取与**数据探活**一律使用触发人自身保存在个人设置中的 DTB 令牌（未配置返回明确错误，绝不在后台定时任务中静默借用他人个人令牌）。所有发往 DTB 执行器的查询均记入 `QueryAudit` 审计记录；归档项目（`409`）与文档型项目（`422`）拒绝触发，同项目并发运行通过数据库互斥约束拒绝（`409`）。
3. **三段漏斗外键发现与严格受控的数据探活**：候选**外键关系**先在本地零扫库完成三路召回（查询历史高频等值 Join、列名/类型与语义相似度、已有**维度值**值域交集），再对 Top-K 候选在单次运行候选上限、并发上限与单条超时预算内执行两步**数据探活**：分区表复用现有分区元数据解析强制仅查最新单分区（无可用分区或超时直接失败关闭为跳过，不退化为全表扫描），非分区表强制子查询采样上限（默认 `1000` 行），先后核验子表非空采样值命中父表列的包含度（默认阈值 >= 80%）与 `LIMIT 1` 探活 JOIN 命中结果。系统仅将重合率、采样数、命中状态与探活分区等聚合指标写入核验证据，严禁将业务事实表数据行写入知识库或应用数据库。
4. **强制收敛为待审批纠错提案与可选评测题集草稿**：挖掘出的高频**指标**/**口径变体**、表/字段默认过滤约束以及核验通过的**外键关系**统一过 L1 静态门禁后，生成 `source="discovery"` 的**纠错提案**，**一律默认进入 `pending` 待审批状态**（不受项目主动纠错或自主演化自动生效开关影响），批准后写入 `overrides/semantic_overrides.yaml`、触发增量构建并支持 `git revert`。管理员触发时可显式勾选（默认关闭）将高频且通过 `validate_sql` 校验的脱敏查询以 `answer_confirmed=false` 沉淀为隔离**评测题集**待确认草稿。

## Considered Options

- **允许项目管理员手写任意 SQL 查询历史表并接入后台定时调度**：任意 SQL 模板扩大注入与慢查询风险，且定时调度在个人 DTB 令牌模式下会演变为静默借用他人凭据，违背最小权限与审计原则，故放弃。
- **探活通过后自动直写源目录或应用数据库**：冷启动阶段从历史日志和抽样核验产出的业务口径与外键仍可能存在临时测试表、旧口径残留或偶发值域巧合，绕过人工确认极易污染知识库，故统一收敛为默认待审批**纠错提案**。
- **在工作流中保存事实表抽样行供前端审批预览**：违背“维度值是唯一进入知识库的真实数据”及业务数据不落盘原则，故仅持久化聚合核验证据。

## Consequences

- `CorrectionProposal` 扩展支持受信任内部来源 `source="discovery"`，前端审批页与筛选项同步展示「历史发现」标签及核验证据摘要（历史频次、去重调用数、采样包含度、探活 JOIN 状态与探活分区）。
- 应用启动恢复器须同步将异常中断的 `running` 知识发现运行安全标记为 `incomplete`，项目永久删除流程须同步清理知识发现运行记录与配置。
