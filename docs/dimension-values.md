# 维度值

规范 `dimension_value` 每条记录是一个文本单元格；同一维度行的单元格可提供相同的 `row_id`。只有同一表、同一 `row_id` 且字段名前缀相同的 `<前缀>_type`、`<前缀>_code` 或 `<前缀>_id` 与 `<前缀>_name` 配对；名称可检索到代码值。没有 `row_id` 或名称不符合规则时不推断关联。来源必须仅提供维度表的值。检索按去除首尾空白后的值去重计数，返回原值以供 SQL 使用；超限字段只保留至多五个原值样例。默认上限 1000，设置对下次构建生效。

全文索引采用 Neo4j `cjk` analyzer，以支持中文分词；维度值不进入向量索引。旧构建需重新构建后才有此索引和收录状态。
