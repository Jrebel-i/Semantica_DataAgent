工作台离线字体来自 Fontsource 的 `@fontsource/ibm-plex-sans` 5.3.0、`@fontsource/ibm-plex-mono` 5.3.0、`@fontsource/noto-sans-sc` 5.3.1 和 `@fontsource-variable/newsreader` 5.3.0。只保留工作台需要的 WOFF2 字体及 Noto Sans SC 的 Unicode 分段样式；各字体的 SIL Open Font License 随文件附带。下载包通过 npm registry 的 SHA-512 完整性校验。

助手正文的衬线字体使用 Newsreader 5.3.0 的 latin 可变字体（normal 与 italic 两个可变字重文件），不引入其他字符集；OFL 许可证见 `newsreader-LICENSE.txt`。中文衬线走系统字体回退，不打包中文字体。
